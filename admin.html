GitHub connection

This lets the admin page save your changes directly to your GitHub repository. Your token is stored only in this browser.

How to get a token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under “Repository access” pick Only select repositories and choose this repo. Under “Repository permissions” set Contents to Read and write. Generate, then paste it above.

Anyone can open this page, but nobody can save changes without the token. Don't use it on a shared device.
